# PromoModal — модалка с каруселью

Модальное окно со встроенной каруселью для онбординга: слайды «картинка + заголовок + текст», навигация **Назад / Дальше**, точки-пагинация, круглая кнопка закрытия.

Источник дизайна: Figma `PromoModal_Desktop`.

## Файлы

- Стили: `components/promo-modal.css`
- Логика: `components/promo-modal.js` (`openPromoModal`)

## Подключение

```html
<link rel="stylesheet" href="../../_design-system/tokens.css">
<link rel="stylesheet" href="../../_design-system/components/buttons.css">
<link rel="stylesheet" href="../../_design-system/base.css">
<link rel="stylesheet" href="../../_design-system/web.css">
<link rel="stylesheet" href="../../_design-system/components/promo-modal.css">
<script src="../../_design-system/components/promo-modal.js"></script>
```

Требует `buttons.css` (кнопки `btn-secondary-md` / `btn-primary-md`) и `base.css` (типографика `.heading1` / `.body1`).

## API

```js
var modal = openPromoModal({
  slides: [
    { image: 'photos/1.png', title: 'Заголовок', text: 'Объясняющий текст.' },
    { image: '',             title: 'Второй шаг', text: 'Пустой image → шахматка-плейсхолдер.' },
  ],
  finishLabel: 'Готово',   // лейбл «Дальше» на последнем слайде (по умолч. «Готово»)
  nextLabel:  'Дальше',
  prevLabel:  'Назад',
  originEl: document.querySelector('[data-action="open-help"]'), // элемент-источник
  onFinish: function () {},  // клик «Готово» (перед закрытием)
  onClose:  function () {},  // любое закрытие
});
// modal.close();
```

`slides` обязателен (≥1). Каждый слайд: `{ image, title, text }`. Пустой `image` → плейсхолдер-шахматка.

### Лейаут `window` — заголовок сверху, под ним иллюстрация

Figma `ModalWindow_Desktop`: шапка с заголовком, под ней картинка-иллюстрация, внизу тот же
футер. Нужен, когда содержание слайда — не фото с подписью, а собранная картинка (первый
случай — онбординг секции отчёта в `v-next/report.html`, макет `980:65188`).

```js
openPromoModal({
  layout: 'window',
  slides: [
    { title: 'Заголовок', image: 'media/slide-1.png', width: 576, height: 333, alt: 'Текст с картинки' },
  ],
});
```

- `width` / `height` — размер картинки в CSS-пикселях (файл — @2x). Без них слайд до
  загрузки нулевой высоты, и модалка прыгает, когда картинка доедет.
- Шапка: padding `28/32/20`, заголовок `.heading1`. Тело — `flex: 1`, иллюстрация по центру
  по вертикали: слайды тянутся по самому высокому, поэтому у слайда с однострочным
  заголовком картинка встаёт посередине оставшегося места, а высота модалки не прыгает.
- **Назад на первом слайде скрыт** (`visibility: hidden`), а не задизейблен — так в макете;
  место держит, ширина 100, по ней центруются точки. В лейауте по умолчанию — как раньше.
- Картинка может быть шире 576 (тень за рамкой) — ложится в поле модалки, не режется.
- Точки — строго по центру футера (сетка `1fr auto 1fr`), при любой ширине кнопок.
- **На слайде можно переопределить:** `layout` (`'promo'` / `'window'` — смешанная
  карусель), `nextLabel` (подпись «Дальше» только на этом слайде), `bodyHeight` (минимальная
  высота тела в px, когда высоту модалки задаёт макет, а не самый высокий слайд).
- **`content` вместо картинки** (2026-09-18) — HTML-строка страницы в тело слайда: живой
  текст там, где иллюстрацией был бы скриншот вёрстки (первый слайд онбординга отчёта,
  макет `2690:129422`). Компонент его не экранирует и не стилизует — вёрстку держит
  страница; тело центрует содержимое, как и картинку.

## Поведение

- **Назад** задизейблен на первом слайде (виден, лейаут стабилен).
- **Дальше** на последнем слайде → лейбл `finishLabel`; клик вызывает `onFinish` и закрывает.
- **`originEl`** (опц.): при «Готово» карточка анимированно **схлопывается и улетает к этому элементу** (источник вызова — напр. ссылка-триггер), затем удаляется — показывает, куда вернуться. Закрытие крестиком/Esc/фоном — обычное затухание. Если `originEl` не задан/вне DOM — «Готово» тоже просто затухает.
- **Точки**: ≤5 слайдов — равные (активная тёмная); >5 — окно из 7 вокруг активной, края сжимаются 8→6→4 (iOS-style).
- **Закрытие**: крестик, клик по затемнению (вне карточки), Esc. На время показа блокируется скролл `body`.

## Размеры (по Figma)

- Карточка 640px, скругление 16px, тень `0 8px 16px rgba(0,0,0,0.08)`.
- Картинка слайда 640×340 (`object-fit: cover`).
- Текст: padding `16/32/4`, gap 12. Футер: padding `20/32/32`.
- Кнопка закрытия: круг 28px в углу `12/12`, тень `0 4px 8px rgba(0,0,0,0.08)`, крест 12px.

## JS-хуки

Внутренние действия — через `data-action` (`prev` / `next` / `close`), не через CSS-классы.
